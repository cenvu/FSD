## What is FSD? / FSD là gì?

**Remember the drive. Browse it later. Compare it. Find the change.** FSD — FishSock Differ is a native macOS metadata snapshot and comparison tool. It records filesystem metadata, not copies of file contents. Completed snapshots remain browsable after the source is disconnected. The SQLite catalog stays local.

**Ghi nhớ ổ đĩa. Duyệt lại khi cần. So sánh. Tìm thay đổi.** FSD — FishSock Differ là công cụ macOS native lưu snapshot metadata và so sánh. Nó ghi metadata hệ thống file, không sao chép nội dung file. Snapshot hoàn tất vẫn duyệt được khi nguồn ngắt kết nối. SQLite catalog nằm cục bộ.

## Included / Có trong bản này

- Manual source selection and metadata capture with progress/cancellation. / Chọn nguồn và capture metadata thủ công, có tiến độ/hủy.
- Saved capture history, offline tree browsing, selected-entry details and bounded search within a snapshot. / Lịch sử capture, cây thư mục offline, chi tiết mục đang chọn và tìm trong một snapshot có giới hạn.
- Metadata comparison with profiles, filters and next/previous differences. Snapshot ↔ snapshot persists; live ↔ snapshot and live ↔ live are temporary workspace comparisons, disposed with transient inputs when closed. / So sánh metadata có profile, bộ lọc và chuyển khác biệt trước/sau. Snapshot ↔ snapshot được lưu; live ↔ snapshot và live ↔ live chỉ tạm thời trong workspace, được dọn cùng nguồn tạm khi đóng.
- Metadata-only snapshot JSON export. / Xuất JSON snapshot chỉ chứa metadata.
- Explicit selected-entry **Detected File Type** using the bundled offline helper, one current-source prefix of at most 4,096 bytes. / Chủ động nhận diện loại file đang chọn bằng helper offline đi kèm, một đoạn đầu nguồn hiện tại tối đa 4.096 byte.

## Platform / Nền tảng

**macOS 15 Sequoia or later; Apple Silicon arm64.** A mounted source readable by macOS is required for capture/live compare. The app runs without Homebrew, Go or an external classifier installation.

**macOS 15 Sequoia trở lên; Apple Silicon arm64.** Capture/so sánh live cần nguồn đã mount mà macOS đọc được. Chạy ứng dụng không cần Homebrew, Go hay cài bộ nhận diện ngoài.

Bản thử đầu tiên này **chưa ký Developer ID và chưa notarize**. macOS có thể chặn lần mở đầu; giao diện cho phép tùy phiên bản/chính sách. ## Safety / An toàn

FSD treats selected sources as read-only. Capture does not read file payloads or write markers/catalogs to the source. Completed snapshots remain immutable; partial/interrupted captures never replace the last complete snapshot. Classification runs only on explicit request and stores no sample bytes. **Metadata Match · Content Not Verified** applies to every comparison: this is not checksum verification or proof of a safe backup.

FSD chỉ đọc nguồn được chọn. Capture không đọc nội dung hay ghi marker/catalog vào nguồn. Snapshot hoàn tất không bị sửa; capture thiếu/gián đoạn không thay thế snapshot hoàn tất gần nhất. Nhận diện loại file chỉ chạy khi chủ động yêu cầu và không lưu byte mẫu. **Metadata khớp · Nội dung chưa kiểm chứng** áp dụng cho mọi so sánh: không phải kiểm tra checksum hay chứng minh backup an toàn.

## Important limitations / Giới hạn quan trọng

- First public test; maintain independent backups. Capture spans an interval, not an atomic filesystem image. / Bản thử đầu tiên; giữ backup độc lập. Capture diễn ra trong một khoảng thời gian, không phải ảnh filesystem nguyên tử.
- All Drives is an unavailable destination; Connected Now has no backend. Drive Sets, Auto Capture and library-wide Search are visual placeholders/unavailable controls. / All Drives chưa khả dụng; Connected Now chưa có backend. Drive Sets, Auto Capture và Search toàn thư viện là các mục chưa hoạt động.
- Live-side comparisons are not retained. Use two saved snapshots for persistent comparisons. / So sánh có nguồn live không được giữ lại. Dùng hai snapshot đã lưu để giữ kết quả.
- No HTML/comparison-report export, content hashing/verification, cloud sync or multi-Library. / Chưa xuất HTML/báo cáo so sánh, không hash/kiểm chứng nội dung, cloud sync hay multi-Library.
- Native mounted sources only; embedded ext2/3/4/raw-device production access is not integrated. Stock-macOS NTFS proof is environment-blocked; network volumes are experimental. / Chỉ nguồn native đã mount; ext2/3/4 và raw-device chưa tích hợp production. Kiểm chứng NTFS nguyên bản bị giới hạn môi trường; volume mạng còn thử nghiệm.
- Detection is inferred from current sampled bytes, not historical verification; no universal accuracy or general legacy DOC/XLS/PPT determinism claim. / Nhận diện suy ra từ mẫu hiện tại, không kiểm chứng lịch sử; không cam kết chính xác mọi loại file hay tính xác định chung cho DOC/XLS/PPT cũ.
- Recapture important snapshots older than the August 4, 2026 scanner correction; an older defect could omit a sibling subtree. / Capture lại snapshot quan trọng trước bản sửa ngày 04/08/2026; lỗi cũ có thể bỏ sót cây thư mục cùng cấp.
- **Visual advisory:** the native macOS titlebar may remain system-gray. Manual VoiceOver and physical-media acceptance remain deferred. / **Lưu ý giao diện:** titlebar native có thể vẫn xám hệ thống. Kiểm chứng VoiceOver và nghiệm thu media vật lý chưa thực hiện.
- No notarization, Developer ID or App Store readiness. / Chưa notarize, ký Developer ID hay tuyên bố sẵn sàng App Store.

## Privacy, notices and source license / Quyền riêng tư, notices và license source

The app stores its catalog locally; no runtime cloud sync, analytics or classifier network dependency. Names/paths and exports can be sensitive. Review shared screenshots/logs, and back up the catalog with the app closed. The ZIP does not include a user's catalog.

Catalog nằm cục bộ; không có cloud sync, analytics hay phụ thuộc mạng cho nhận diện lúc chạy. Tên/đường dẫn và file xuất có thể nhạy cảm. Kiểm tra ảnh/log trước khi chia sẻ, backup catalog khi đã đóng app. ZIP không kèm catalog người dùng.

Notices đi kèm nằm tại đường dẫn trên và [trong source](https://github.com/cenvu/FSD/blob/v0.1.0/FSD/Helpers/THIRD_PARTY_NOTICES.txt): filetype MIT, Go license/patent notice và notice mã toán Sun Microsystems được liên kết. Thành phần bên thứ ba giữ license riêng.

# Releases

Store signed internal release artifacts and release notes here only when explicitly prepared for distribution.

Recommended structure:

```text
RELEASES/v0.1.0-alpha.1/
├── FSD-v0.1.0-alpha.1.dmg
├── RELEASE_NOTES.md
├── SHA256SUMS.txt
└── BUILD_MANIFEST.json
```

Do not commit unsigned ad-hoc builds as official releases.
